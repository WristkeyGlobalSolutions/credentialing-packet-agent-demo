# Credentialing Packet Agent — Live Demo

A standalone static demo of a provider credentialing packet agent: completeness checks, confidence-banded routing, quote-or-abstain extraction, and a human pause-and-resume step.

**Live demo:** https://wristkeyglobalsolutions.github.io/credentialing-packet-agent-demo/

- Tap **Run Full Demo** to walk four synthetic provider packets end to end.
- When the demo pauses for a human verification code, enter **123456**.
- Tap **Run Eval** to grade the agent against the golden set (44/44 fields).

All data on this page is synthetic. No real provider, patient, or credentialing data is used, and the page makes no network calls.
